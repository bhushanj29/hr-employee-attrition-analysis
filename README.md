# HR Employee Attrition Analysis

## Project Overview

This project analyzes employee attrition to explore workforce patterns and factors that may be associated with employees leaving an organization.

The project uses Python, SQL, and Power BI to prepare data, perform analysis, and present findings through a dashboard.

## Project Objectives

- Analyze overall employee attrition.
- Examine attrition across departments and job roles.
- Explore the relationship between overtime and attrition.
- Analyze job satisfaction and employee tenure.
- Compare employee counts and salary patterns across departments.
- Present relevant metrics and trends through a Power BI dashboard.

## Tools and Technologies

- **Python:** Data analysis using Pandas.
- **SQL (MySQL):** Filtering, aggregation, grouping, and analysis queries.
- **Power BI:** Interactive dashboard and data visualization.
- **CSV:** Dataset storage.

## Dataset

The cleaned dataset contains 5,000 employee records and 15 columns, including age, gender, department, job role, monthly income, years at company, job satisfaction, overtime, and attrition status.

### Python

### SQL

- Overtime and attrition analysis.
- Job-role-wise attrition.

## How to Use This Project

1. Download the dataset and inspect it.
2. Open the SQL file in MySQL Workbench after creating the required database and table.
3. Open the HTML file in a web browser to review the exported Python analysis.
4. Open the PBIX file in Microsoft Power BI Desktop to explore the dashboard.
